# PulsarNode

PulsarNode orchestrates real-time data ingestion and processing in a auto-scaling environment, utilizing a distributed Manager and Server architecture.

PulsarNode is built to be simple and practical, focusing on doing one thing well.

**Why PulsarNode?**

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/PulsarNode.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

PulsarNode is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
